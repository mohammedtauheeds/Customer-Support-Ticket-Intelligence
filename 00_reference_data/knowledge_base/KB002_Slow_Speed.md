# KB002: Slow Speed

**Applies to:** All home and business broadband plans
**Last reviewed:** 2025-06-30

## Symptoms

Customers typically report: Very slow speed; Not getting promised speed; Speed only 5 Mbps; Buffering issue.

## Resolution Steps

1. Ask the customer to run a speed test on a LAN cable to rule out WiFi.
2. Check the line profile and plan provisioning in the OSS.
3. Recommend 5 GHz band and channel change for WiFi congestion.
4. If evening-only slowness is reported by many users in a node, escalate to the network capacity team.

## Customer Communication

Always confirm the customer ID and registered mobile number before sharing account details. Never ask for OTPs or card numbers.
